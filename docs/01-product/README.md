# Produkt

Katalog opisuje, co demonstrator ma dostarczać, kto z niego korzysta i po czym poznać, że zmiana została wykonana kompletnie. Dotyczy pracy nad fikcyjnymi artefaktami dokumentowymi.

## Zawartość katalogu

| Plik | Co zawiera |
| --- | --- |
| [wymagania.md](wymagania.md) | wymagania funkcjonalne `WF-1` … `WF-7` i niefunkcjonalne `WN-1` … `WN-4`, każde ze sprawdzalnym rezultatem |
| [scenariusze-uzycia.md](scenariusze-uzycia.md) | cztery scenariusze pracy nad dokumentami, każdy z aktorem, warunkiem wstępnym, przebiegiem i rezultatem |
| [role-i-uprawnienia.md](role-i-uprawnienia.md) | cztery role projektowe wraz z macierzą uprawnień do zmiany stanu artefaktu |
| [kryteria-akceptacji.md](kryteria-akceptacji.md) | listy kontrolne dla zmiany dokumentacji, nowego artefaktu i zmiany schematu |

## Kolejność czytania

1. [wymagania.md](wymagania.md) — czego demonstrator ma dostarczać i po czym to sprawdzić.
2. [scenariusze-uzycia.md](scenariusze-uzycia.md) — jak z tego korzysta się w praktyce.
3. [role-i-uprawnienia.md](role-i-uprawnienia.md) — kto co robi i czego nie robi.
4. [kryteria-akceptacji.md](kryteria-akceptacji.md) — kiedy zmiana jest kompletna.
