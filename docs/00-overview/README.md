# Przegląd projektu

Katalog wprowadza w projekt: po co istnieje, gdzie kończy się jego zakres, jakim językiem jest opisany i w jakim stanie się znajduje. Czyta się go przed każdym innym katalogiem dokumentacji.

## Zawartość katalogu

| Plik | Co zawiera |
| --- | --- |
| [cel-i-zakres.md](cel-i-zakres.md) | cel projektu, zakres włączony, zakres wyłączony, granice interpretacyjne |
| [glosariusz.md](glosariusz.md) | definicje pojęć obowiązujące w całym repozytorium oraz terminy sporne |
| [ograniczenia-i-zasady.md](ograniczenia-i-zasady.md) | dane wyłącznie syntetyczne, brak zastosowania rzeczywistego, wymóg jednoznacznego języka |
| [status-projektu.md](status-projektu.md) | stan dokumentacji, kamienie milowe, ryzyka stałe wraz z kontrolą ograniczającą każde |

## Kolejność czytania

1. [cel-i-zakres.md](cel-i-zakres.md) — najpierw granice, bo one rozstrzygają, czego w tej dokumentacji nie ma i nie będzie.
2. [ograniczenia-i-zasady.md](ograniczenia-i-zasady.md) — zasady obowiązujące każdy dokument i każdy przykład.
3. [glosariusz.md](glosariusz.md) — pojęcia; termin użyty inaczej niż tam jest błędem dokumentu.
4. [status-projektu.md](status-projektu.md) — stan bieżący wraz z kontrolami.

Dalej: [wymagania i scenariusze użycia](../01-product/README.md), potem [architektura i decyzje](../02-architecture/README.md), a na końcu [procedury](../03-procedures/README.md) czytane łącznie ze [szablonami](../04-templates/README.md) i [przykładami](../../examples/).
